# Rev A 조립 참고

이 문서는 디지털 설계의 조립 의도를 설명한다. 실물 시험과 공차 보정이 아직 필요하다.

## 보존하는 원본

다리 링크·발바닥·모터·목·카메라·머리 전자부품은 원본 그대로 둔다. 임의의 원본 나사 위치를 추정해서 새 외장에 복제하지 않았다. 머리 외장은 자체 브리지와 M2 체결구, 몸통 부품은 스트랩 장착을 시험하는 구조다.

## 새 부품

1. **두개골 외장**: 좌우 `skull_cheek_*`와 `head_bridge_1/2`. 좌우 안쪽 면은 Y=±44 mm, 브리지 보스가 이 면에 닿는다. 조립 기준은 원본 MJCF의 영점 자세이며 단위는 mm.
2. **이빨·눈썹**: 바깥 면에 부착하는 장식 부품. 기존 입 모터와 기구는 변경하지 않는다. 이빨은 실제 물기용이 아니다.
3. **앞발**: `forearm_*`와 `arm_standoff_*`의 지름 2.4 mm 구멍을 맞춘다. 브래킷 스트랩 채널은 3×4 mm. 실제 케이스와의 맞물림은 확인 전이다.
4. **꼬리**: `tail_segment_1/2/3`와 `tail_saddle`. 장착판 슬롯은 3×17 mm. 분할 꼬리는 접합/접착 길이 확인이 필요하다. 테스트용 일체형 파일도 `models/print/tail_continuous.stl`에 제공한다.
5. **체결구 후보**: 머리용 M2×12 4개, 앞발용 M2×16 2개, M2 너트 6개. 이는 보스·외장 두께에서 산출한 시작 후보이며 체결 길이/공구 접근성은 실물에서 확인해야 한다. 스트랩 너비는 3 mm 슬롯보다 작아야 한다.

## 출력 파일

- `models/print`: 출력면이 Z=0, XY 중심이 원점. 기본 STL 단위는 mm.
- `models/parts`: 조립 참조 좌표. 이 파일을 일괄 불러오면 외장 조립 위치를 유지한다.
- `models/step`: 동일 부품의 편집 가능한 CAD 솔리드.
- `models/micro_rex.glb`: 원본 메커니즘과 새 외장을 포함한 전체 시각 모델. 단위 m.
- `models/micro_rex_retrofit.step`: 새 외장의 CAD 조립. 원본 STL을 가짜 편집형 솔리드로 변환하지 않았다.

처음부터 전체를 출력하기보다 구멍/슬롯과 브리지 한 세트를 먼저 확인한다. 프린터별 수축과 구멍 오차를 실제 시편으로 측정한 뒤 CAD 수치를 조정한다.

## 검증 상태

원본 제어 관절의 이름/순서/축/범위, 센서, 액추에이터 연결과 제한은 비교 검사했다. 추가 외장 질량과 관성은 몸체 관성에 합산했다. 외장 충돌 모델은 보수적인 바운딩 박스이며 구멍과 복잡한 오목 형상을 정확하게 표현하지 않는다.

원본과 Micro Rex 모두 기본 XML PD로 HOME 자세를 3초 유지하는 시험에서 넘어졌다. 이 결과는 학습된 정책을 사용한 보행 평가가 아니며, 파일 컴파일 성공을 안정적인 로봇 동작으로 확대 해석해서는 안 된다. 추가된 47.68 g과 무게중심 변화는 정책 재검증 또는 재학습 대상이다.

미검증: 실제 원본 제품과의 외장 간섭, 배선 경로, 전체 관절 가동 중 간섭, 카메라 전 시야각, 꼬리 고정 강도, 낙하/피로, 발열, 실제 재료 질량, 입 모터 동작, 보행 및 복구 정책.
